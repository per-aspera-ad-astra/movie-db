# 🎬 Movie DB

**Movie DB** is a modern React application for browsing movies by genre, sorting, filtering by year, and exploring cast members — all powered by the [TMDB API](https://www.themoviedb.org/documentation/api). It features infinite scrolling, a dark theme, and a clean responsive UI.

## 🚀 Tech Stack

- **React + TypeScript** – Component-based architecture with type safety
- **React Router** – Client-side routing
- **Tailwind CSS** – Utility-first styling
- **shadcn/ui + Radix UI** – Accessible and customizable UI components (Selects, Modals, etc.)
- **TMDB API** – Source for movies, genres, cast, and posters
- **Vite** – Fast development and build tool

## ✨ Features

- 🔎 Genre-based movie filtering
  - Sort by popularity, release date, rating, or revenue
  - Filter by year
  - Reset filters to default
- 📥 Infinite scrolling for movie lists
- 🎞️ Movie cards with fallback poster images
- 👥 Cast display on movie details
- ❌ Custom 404 page
- 🧭 Sidebar navigation by genres
